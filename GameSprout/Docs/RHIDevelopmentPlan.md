# 通用 RHI / Metal 首版协作计划

状态：计划稿，尚未开始代码实现。阶段工作日为估算，不是已消耗时间。

## 1. 范围与预算

当前只实现 Metal 后端，主计划在约定 macOS 真机上验收。公共接口同时对照 Vulkan、Direct3D 12、现代桌面 OpenGL 完成映射审查；不在此计划中实现这三个后端。Qt 后续自行接入，不作为本轮任务。

目标是能长期支撑体素游戏所需常规图形能力的 RHI：资源、绑定、绘制管线、命令、多 Pass、同步、呈现/离屏及诊断。体素算法、资产文件加载、相机/灯光业务、动画、物理、游戏规则与 AI 制作均属于上层，不计入本轮。

- 基准实施与验证：**39 个工作日**。
- 返工与集成余量：**6 个工作日**。
- 计划目标：**45 个工作日，约 9 个五日工作周**。
- 当前粗估区间：**35–55 个工作日**；45 日是排期基线，不是精确交付保证。
- 工作日按你我持续协作的有效工程投入计算，已计入 AI 辅助设计、编码、测试和排错，不再另乘折扣。实际日历时间受投入与设备可用情况影响。
- D1 从正式开始实施计算，不在本稿中自动指定日历开始日期。计划不会自动创建后台任务或提醒。

## 5. 完成标准

1. 公共 API 不依赖 Metal/Apple 图形头或 Qt；平台 Surface 的原生入口与后端内部隔离。
2. 资源、绑定、Pass、访问/同步、Shader 与呈现各自有明确契约、错误行为和后端映射。
3. Metal 真实运行样例覆盖贴图、深度、混合、实例化、多 Pass、离屏采样、动态更新、读回和生命周期。
4. 资源销毁与 GPU 在途使用有明确关系；不以每帧等待设备空闲掩盖同步问题。
5. 压力/持续运行结果记录样例规模、设备、系统、构建模式、分辨率及观察时长；性能指标需按该环境定版。
6. Vulkan、D3D12、OpenGL 的状态是“公共设计映射已审查”，不是“已运行支持”。真实兼容性在未来对应后端落地时继续验证。
7. 交付源码、独立构建入口、后端无关样例、验证方法、能力清单、已知限制和使用说明。
