场景源文件 V1

.scene 是 Assets 内可编辑的 JSON 源文件。AssetsManager 管理其 .meta 和 GUID，
AssetsPipeline 导入为 Library/Artifact 内的二进制产物；SceneManager 不生成 Meta。

顶层字段：Version=1、Name、Objects，以及可选 MainCameraID（0 表示未指定）。
RootActive 默认 true，RootComponents 可记录场景根自身的组件，根 Transform 必须为单位变换。
RootMainCamera=true 表示根上的 Camera 是主相机，此时 MainCameraID 必须为 0。
NextObjectID 保存节点和组件共用的文件 ID 分配高水位，新增身份单调分配，删除后重开也不复用。
NextObjectID 缺省使用已有最大 ID+1；0 表示 uint64 ID 空间耗尽。
Objects 每项包含 ID、Name、Components；ParentID 默认 0，Active 默认 true。
Layer 保存 0..31 固定编号，默认 0；TagID 保存项目稳定 Tag 身份，默认 0（Untagged）。
StaticFlags 是 uint32 位集合，默认 0，当前合法位为 1、2、4、8、16、32、64；未知位拒绝加载。
场景根使用 RootStaticFlags。静态标志只保存作者声明，不冻结 Transform，不停用脚本，也不改变刚体类型。
SetObjectStaticFlags 事务按 changedFlags 逐节点修改，包含子节点时为一个 Undo/Redo 步骤，保留各节点其余位。
StaticAuthoring 负责报告真实功能支持度：本版所有烘焙系统未接入，禁止新启用，允许清除已有标志。
场景根用 RootLayer、RootTagID 保存同类属性。名称重命名不改编号或 TagID，父子不自动继承。
加载宿主须先向 Runtime 注入项目定义；未定义 TagID 在创建任何对象之前拒绝，不静默降为 Untagged。
项目配置存于 ProjectSettings/ProjectSettings.json：内置 Layer 0 Default、1 Ignore Raycast、2 UI，
其余可命名；碰撞矩阵与相机/射线掩码共享 Layer 编号，后两者的筛选与碰撞矩阵独立。
Collider 不再保存独立 CollisionLayer/CollisionMask，读取所属节点 Layer 和项目碰撞矩阵。
ID 是本场景文件内稳定的节点标识，不能使用每次创建后变化的 Runtime InstanceID。
ParentID=0 代表直接位于场景根下。文件可以先写子节点，再写父节点。
组件序列化也保存非零稳定 ID，与节点 ID 在同一文档内唯一；它不是脚本 InstanceID 或 Runtime 指针。

资源引用使用 {"Guid":"32位十六进制字符串","LocalID":非零整数}。
未绑定资源时省略该字段或使用 null，不能写空 Guid 和 LocalID=0 的引用对象。
MainCameraID 指向包含 Camera 组件的节点。
Light 使用 Settings={Type:"Directional",Enabled:true,Color:[1,1,1,1],Intensity:1,CullingMask:4294967295}。
Color 是线性 RGB（允许 HDR）与 0..1 Alpha，Intensity 为非负有限数，CullingMask 按目标对象 Layer 过滤。
方向光沿节点局部 -Z 发射；位置和缩放不影响光照方向或强度。当前只支持 Directional 类型，未知字段/类型直接报错。
Light 属于普通节点，不能挂到 Scene 根；Scene 与 Prefab 使用同一组件值格式，支持事务快照、实例 Override 和独立实例化。

启动尝试恢复本项目 UserSettings/EditorState.json 中的 LastScenePath（相对 Assets）。
没有有效记录时建立未保存的 Untitled 场景，默认有 Main Camera。打开、另存为成功后原子记录路径，退出不自动保存场景修改。
Project/Create/Scene 仅创建文件并交给已有资源流程导入，不自动切换场景。
双击 Scene 源资产时加载候选场景，校验及创建成功后切换；失败保留当前场景。
HierarchyUI 只存节点 ID 和展示数据，通过 Runtime 事件刷新，不另外维护运行节点树。

Hierarchy 右键可在场景根或指定父节点下创建节点：空对象、Camera、Mesh、UI Canvas、
UI Image、UI Empty。节点和组件由 Runtime 工厂创建，同父重名自动编号。
SelectionManager 用 SceneID/ObjectID 共享节点选择，与 Project 的资源选择互斥。
Inspector 按对象身份解析组件，事件发生时重新查询 Runtime。

保存与属性编辑
SetObjectLayer 由 SceneManager 执行单对象或整棵子树的 Layer 修改，包含子节点时为单个 Undo/Redo 事务。
View 不解析和改写节点 JSON；Tag/Layer 都不会自动继承父节点。
GetReferencedTagIDs 向项目设置服务提供当前/挂起文档 Undo/Redo 与 Prefab annotations 的 Tag 身份快照，
删除定义时连同活对象及已保存源文档一起检查，避免清空当前引用后破坏已有撤销记录。
SceneDocument 的 ObjectIDs 将 Runtime InstanceID 映射为稳定文件 ID，文件中不保存 Runtime 身份。
属性与变换历史同样以稳定文件 ID 定位目标；0 表示当前场景根，不能删除场景根。
DeleteObject 记录被删子树完整节点/组件数据、父级文件 ID、兄弟位置与内部主相机。
Undo 只重建此子树，保留稳定文件 ID，分配新的 Runtime 身份，不重建场景或未删节点。
Redo 检查子树未被历史之外的操作改动，避免旧快照覆盖新节点或属性；失败保留历史位置。
序列化按深度优先顺序写入对象，保留每组兄弟顺序、所有可编辑组件属性、资源 GUID/LocalID、主相机及根状态。
Mesh Bounds 等从加载结果派生的数据不保存。Missing 资源的合法身份仍保留，不要求资源当前存在。
EditObject 保存只捕获值的 apply/revert 操作，执行前在活动场景按 ID 查询目标。
成功后记录属性撤销历史；失败或抛异常尝试恢复原值，不改变历史位置。目标已删除时 Undo 安全失败。
当前场景切换后清空撤销历史；节点删除和模型实例化可撤销/重做。
SaveScene 要求已有当前路径；SaveSceneAs 可首次创建新文件，不静默覆盖别的已有场景。
路径必须位于已有 Assets 子目录中，禁止符号链接；使用 QSaveFile 原子替换，不允许直接写回退。
保存成功后才更新当前路径和基线，资源 watcher 自然接收源文件变化，不直接生成 Meta/Artifact。
打开和成功保存时另存原始文件字节 SHA256。覆盖当前路径前、提交前均核对磁盘，外部修改（含格式变化）
或文件消失时拒绝覆盖，提示重新打开或另存为新文件；另存到新路径不受旧路径冲突影响。
HasUnsavedChanges 比较当前完整快照与保存基线，也能发现尚未派发 Runtime 事件的外部 setter。
常规 Update 仅在本批 Runtime 事件发生后比较快照；迟到事件不会把刚保存的相同数据重新标脏。
OnSceneStateChanged 通知属性/历史/保存状态变化，不触发场景切换及选择清空。
编辑/Undo/Redo/Save/Open 不能从 Runtime 更新、遍历或事件回调重入执行。

Prefab 作者记录
Annotations.PrefabInstances 保存实例 Source(Guid/LocalID)、RootFileID、SourcePath、SourceHash、
Baseline、Mappings 与 Overrides。Objects 仍保留完整展开对象图，普通 Inspector 编辑同一组 Runtime 对象。
Mappings 同时保存源节点/组件 ID 与场景文件 ID；脚本内部对象引用随实例重映射，资源引用保持原 GUID/LocalID。
PrefabManager 负责来源追踪与覆盖合并；SceneManager 只提供通用子树捕获/替换事务和 annotations 持久化。
EditObjectDocument 在一个撤销事务内提交对象图和作者记录，支持失败回滚，不通过私有实现耦合 PrefabManager。
打开、保存、Undo/Redo 和 Play 作者快照保留 annotations。场景离线导入先根据最新 Prefab 源合并实例覆盖，
记录源依赖，再剥离 annotations，Player 产物只包含完成展开的当前对象图，运行时不处理 Apply/Revert。
Nested/Variant 仅预留数据边界，本版拒绝嵌套实例及非空 Base/NestedInstances。

职责与生命周期
环境光照是场景数据：顶层 EnvironmentLighting 保存 Mode（None/Color/Gradient/SphericalHarmonics）、
AmbientColor、SkyColor、EquatorColor、GroundColor（线性 RGBA，RGB 可为 HDR）、Intensity 及 SHCoefficients。
SHCoefficients 是 9 个有符号 RGB 三元组，已经包含漫反射卷积及 E/pi，基底顺序为
[1,y,z,x,xy,yz,3*z*z-1,xz,x*x-y*y]，着色器不得重复乘归一化系数或 pi。
省略 EnvironmentLighting 使用正常的 None 默认；未知字段、未知 Mode、错误数组长度、非有限值严格拒绝。
环境随完整 Scene/Play 作者快照保存和恢复；Prefab 及普通子树不携带场景环境。
LightingAuthoring 通过 ObjectEditing 对场景根执行可撤销事务；Play 写临时运行世界，不保存源 .scene。
Module 订阅 Scene/Play/Runtime 环境事件并推送值快照，View 不通过帧轮询更新环境控件。
编辑器应用组合层创建并销毁 Runtime，经 EditorApi 的 const _Runtime 指针统一注入；Module 和 View 只借用。
RuntimeHost 仅管理资源提供者连接、时钟和唯一每帧 Update，不创建或 delete Runtime。
SceneManager 管理 .scene 文档、活动场景、稳定文件 ID、保存基线和场景编辑事务，不拥有 Runtime、GPU 或动画时钟。
AnimationPreview 管理临时单 Clip 与场景 Animator 预览，使用 Runtime 的采样能力；它请求宿主推进时间，不自己再次 Update。
SceneView 使用独立编辑相机，GameView 使用游戏相机；两者通过 Runtime 视口 API 绘制，不直接操作 GRHI。
编辑器关闭时先停止 PlayMode 会话，再释放全部 View、预览、场景、宿主与其他资源服务。
SceneManager 只销毁自己拥有的活动场景；RuntimeHost 在场景和视口退出后断开资源提供者；应用组合层在所有 Module 退出后销毁 Runtime。

运行会话
PlayMode 通过 ISceneManager::BeginPlaySession / EndPlaySession 协调运行，不访问 SceneDocument 私有实现。
进入前脚本执行必须关闭；捕获当前内存中的全部场景，不重新读取磁盘文件，未保存编辑也参与运行。
文档路径、原始磁盘哈希、保存基线、Undo/Redo 及稳定 FileID 分配状态随作者快照保留。
完整验证并构建候选世界后才发布新活动场景；候选失败不会丢失原世界或编辑历史。
运行期间拒绝作者属性/组件/结构编辑、Undo/Redo、保存和打开场景；运行节点事件不触发作者快照比较。
HasUnsavedChanges 在运行期间返回进入前作者状态。脚本新增节点没有作者文件 ID，查询不会序列化运行世界。
停止先由宿主释放脚本实例，再恢复作者快照；清理运行期间的全部场景，包括后来创建的其他场景。
运行场景本身被删除、或运行数据暂时不满足源场景格式，也不会影响作者快照恢复。
OnPlaySessionChanging 在旧世界仍可读取时触发；活动场景切换通知后清理旧世界，再触发 OnPlaySessionChanged。
SelectionManager 保存作者 FileID / 资产身份，进入时映射到运行节点，停止后映射回恢复节点；不保留旧节点指针。
